## 📊 Project Overview
This project presents an **end-to-end Power BI analytics solution** for **Uber’s NCR ride-booking dataset**.  
It transforms raw operational data into **actionable business insights**, showcasing expertise in **data modeling, DAX formulation**, and **data storytelling through visualization**.

The dashboard analyzes:
- Ride booking and cancellation trends  
- Customer satisfaction metrics  
- Vehicle utilization patterns  
- Operational inefficiencies and driver behavior  

---

## 🎯 Objectives
- Design and build an interactive **Power BI dashboard**.  
- Perform **data cleaning and transformation** using Power Query.  
- Implement **DAX measures** to calculate KPIs and metrics dynamically.  
- Provide **business insights** and **data-driven recommendations** for performance improvement.

---

## 🧠 Key Insights
- **148.8K total bookings** analyzed — only **62% completed successfully**.  
- **Driver cancellations (18%)** are the largest cause of inefficiency.  
- **Go Sedan**, **Go Mini**, and **Auto** dominate customer demand.  
- **Low 5-star rating ratio (6.5%)** highlights opportunity for quality improvement.

## ⚙️ Technical Implementation

### 🧩 Tools & Technologies
- **Power BI Desktop** – Data modeling and visualization  
- **Power Query** – ETL and data transformation  
- **DAX (Data Analysis Expressions)** – Custom KPI measures  
- **LaTeX** – Professional report documentation  

### 🔍 Data Source
Dataset: [Uber Ride Analytics Dashboard — Kaggle](https://www.kaggle.com/datasets/yashdevladdha/uber-ride-analytics-dashboard)

Contains booking details including:
- Booking status and timestamps  
- Vehicle types  
- Customer feedback and ratings  
- Cancellation reasons

## 📈 Dashboard Features

| Visualization | Purpose |
|----------------|----------|
| **KPI Summary Cards** | Display core business metrics (bookings, cancellations, ratings). |
| **Booking Status Pie Chart** | Breakdown of completed vs. cancelled rides. |
| **Monthly Trend Line Chart** | Shows booking patterns over time. |
| **Vehicle Type Bar Chart** | Highlights popular and underperforming vehicle categories. |
| **Cancellation Reason Table** | Displays primary customer-side cancellation reasons. |

---

## 💡 Recommendations
1. **Reduce Driver Cancellations** – Launch incentive programs; monitor driver-side performance.  
2. **Optimize Driver Supply** – Use geospatial analysis to address “No Driver Found” issues.  
3. **Enhance Customer Experience** – Improve address accuracy, app usability, and driver training.  
4. **Focus on High-Demand Categories** – Prioritize Go Sedan, Go Mini, and Auto in promotions.
